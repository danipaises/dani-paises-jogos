Uma TV. Até oito pilotos.

O modo normal funciona direto no navegador. Para reunir celulares na mesma rede Wi-Fi, inicie o servidor em um PC ou no Termux e abra o link da TV mostrado no terminal.

cd countryballs-world-kart
npm install
npm start

No Termux, instale antes: pkg install nodejs. No computador, instale Node.js. Conecte o computador à TV por HDMI para menor atraso.
