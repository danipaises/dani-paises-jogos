Como você quer jogar?

Não precisa de PC: um celular com Termux pode criar a sala e mostrar a corrida na TV por espelhamento.

📷 Entrar em uma sala

Abra a câmera do celular e escaneie o QR code que aparece na TV. O primeiro jogador a entrar será o mestre da sala.

Todos precisam estar na mesma rede Wi-Fi.

📱 Criar sala no Termux

Abra o Termux no Android, cole o comando abaixo e aguarde. Depois abra o link da TV que aparecer no terminal.

pkg update -y && pkg install -y nodejs git &&
(git clone https://github.com/danipaises/dani-paises-jogos.git "$HOME/dani-paises-jogos" || git -C "$HOME/dani-paises-jogos" pull --ff-only) &&
cd "$HOME/dani-paises-jogos/countryballs-world-kart" && npm ci && npm start

💻 Criar sala no Ubuntu

Com Node.js 22+ e Git instalados, cole no terminal:

(git clone https://github.com/danipaises/dani-paises-jogos.git "$HOME/dani-paises-jogos" || git -C "$HOME/dani-paises-jogos" pull --ff-only) &&
cd "$HOME/dani-paises-jogos/countryballs-world-kart" && npm ci && npm start

O site mostra as instruções; iniciar o servidor exige executar o comando no Termux ou no Ubuntu. Mantenha o terminal e a tela da TV abertos durante a partida.

Escaneie para correr

O primeiro a entrar será o mestre e escolherá as regras.
